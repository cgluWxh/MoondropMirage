# Mirage Menu Bar

MOONDROP MIRAGE 的轻量 macOS 菜单栏控制器。它是独立工程，不依赖也不修改仓库根目录的 CLI。

## 功能

- 菜单栏显示左右耳较低的一侧电量。
- 监听 MIRAGE 的系统蓝牙连接事件；连接后读取三项电量、发送系统通知，并立即释放 RFCOMM。
- 耳机当前已连接 macOS 时，每 10 分钟短连接读取一次电量并更新菜单栏；不会主动唤醒未连接的耳机，读完即释放 RFCOMM（浮窗正在使用时除外）。
- 监听断开事件并立即清除菜单栏电量，不发送断开通知。
- “菜单栏显示电量”开关会持久保存；关闭后隐藏数字，并停用连接事件与十分钟自动刷新。
- 耳机连接时显示菜单栏项目，断开时隐藏；首次启动或再次打开 App 时会临时显示 8 秒，提供控制和退出入口。
- 悬浮窗显示左耳、右耳、充电盒电量。
- 查询并切换 ANC：关闭、自适应、通透、抗风噪、降噪。
- 查询和开关双设备连接。
- 设置双设备关闭时间：关闭、5、10、30、60 分钟。
- 查看两个连接槽位并按 MAC 断开指定设备。
- 仅在打开浮窗时连接耳机；关闭浮窗 10 秒后释放 RFCOMM 连接，10 秒内重新打开会复用并取消断开。

## 构建

```bash
chmod +x build-app.sh
./build-app.sh
open "build/Mirage Menu Bar.app"
```

首次启动前，请先在 macOS 系统设置中配对并连接 `MOONDROP MIRAGE`。系统请求蓝牙权限时请选择允许。

当前是个人验证版，使用本机 ad-hoc 签名，不包含自动更新、开机启动或正式发行签名。
